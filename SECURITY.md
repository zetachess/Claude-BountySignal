# Security Policy

Claude-BountySignal is a security-testing tool and must be used only on assets that are owned by the operator, provided as a practice lab, or covered by explicit written authorization.

Do not use it to obtain credentials, access unrelated accounts, extract personal data, evade rate limits, or expand an engagement beyond its approved scope.

## Reporting a problem in this project

Please report vulnerabilities in Claude-BountySignal itself privately to the repository maintainers. Do not include live credentials, session tokens, personal data, or sensitive target information in an issue.
