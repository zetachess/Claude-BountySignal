# /auth-report

Use the report template in `templates/vulnerability-report.md`.

The report must distinguish:

- authentication failure;
- session integrity failure;
- authorization failure;
- chained impact.

Use only evidence supplied by the user or collected within the approved scope. Never fill missing facts with plausible details.
